# tilt 30° FFT+ICP — 2차 계획 (오프라인 하네스 기반)

작성 2026-09-02. 1차(E0~E13·w0~w1)는 `SUMMARY.md`, 인계는 `HANDOFF.md`.

## 이 계획이 존재하는 이유

1차는 **판별력이 없었다.** bag 재생 끝의 궤적 오차 하나로 판정했는데 같은 설정
복제 산포가 22% 였다. 그 잡음바닥 아래로 E4·E1c·E12·E13 전부 "동률"로 떨어졌고,
살아남은 결론은 승자 설정(626% 개선)·CFAR 양방향 기각·키프레임 간격 기각 셋뿐이다.
즉 **1차의 "기각" 대부분은 진짜 기각이 아니라 측정 실패**일 수 있다.

2차는 측정을 바꾼다. 최적화 대상인 **FFT 병진 오차를 직접** 재고, ICP·팩터그래프·
NSSM 이 섞이기 전에 판정한다.

## 진단 — 지금까지 확정된 것

1. **D6 몸체고정 거리 띠.** tilt 30°·고도 4 m·수직 FOV 20° 에서 바닥 반사는
   수평거리 ρ∈[5.5, 12.6] m 에만 든다. 직교영상 497행 중 내용이 있는 건 ~86행.
2. **병목은 병진 단독.** 게이트 기각 117건 중 병진이 관여한 것 117건(100%),
   회전은 4건(3%)뿐이고 회전 단독 기각은 0건. 회전 오차 중앙값 2.04°/게이트 10°.
3. **DR 은 시드일 뿐 자세가 아니다.** `factor_icp=184` 대 `factor_odom=1`,
   `slam_icp_noise` 시그마가 `slam_odom_noise` 의 절반(정보행렬 4배).
   그래프는 사실상 ICP 만 듣는다.
4. **회전-후-병진 분리는 이미 구현돼 있다.** `estimate_translation` 은 회전을
   보상해 img2 를 돌린 뒤(`localization_fft.py:945-953`) 상관한다. 표준 FMT
   파이프라인이고, 인계문의 D4(회전 고정 후 병진 재추정)는 이미 된 것이라 폐기.

## 문헌 조사에서 나온 것

구현의 근거 논문은 Hurtós et al. 2015 (FLS Fourier 정합). 조사 결과 **구현이
문헌 표준에서 빠뜨린 것 하나**가 있다.

- **마스킹 상관이 없다.** 큰 0 영역을 가진 영상을 그냥 위상상관하면 0 영역이
  metric 에 그대로 들어가 **zero-shift 로 편향**된다. 표준 처방은 Padfield 의
  masked FFT normalized cross-correlation — "영상을 마스킹한 뒤 상관"과 **다르며**,
  마스크 밖을 완전히 무시한다. 497행 중 86행만 내용인 tilt 30° 는 이 편향의
  교과서적 조건이고, 관측된 "병진 과소추정"과 방향이 맞는다. → B2
- FMT 표준(로그폴라 회전 → 회전보상 → 병진 위상상관)은 이미 구현됨(위 4).
- `phase_cross_correlation`(scikit-image)의 마스킹 구현은 위상상관이 아니라
  zero-normalized cross correlation 이다. 그리고 이 컨테이너는 numpy 1.23.5 핀과
  `opencv-python 5.0.0.93`(numpy>=2 선언)이 모순이라 **리졸버로 새 패키지를 깔면
  8년 전 버전이 조용히 깔린다** → 설치하지 말고 numpy 로 직접 구현한다(~30줄).

## 코드 감사에서 나온 후보

- **CLAHE 가 거의 0 인 영상에 걸린다.** `estimate_translation` 은 상관 직전
  `cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))` 를 건다
  (`localization_fft.py:975-977`). 내용/공백 경계 타일에서 대비를 끌어올려
  잡음을 상관에 주입할 수 있다. tilt 10° 는 내용 비율이 커서 덜 해롭고, 실제로
  seed_fft 가 tilt10 66% vs tilt30 39% 다. → B1
- **주기분해가 직교 패스에서 꺼져 있다**(`apply_periodic_decomp=False`,
  주석 근거: Moisan 은 전체 영상을 가정). 그런데 영상은 0 패딩돼 있어 경계
  불연속 누설은 실재한다. 창함수(Hann/Tukey)가 대안. → B6
- **피크가 단일이다.** ICP 수렴률이 1.000 이므로 상위 N 피크를 다 시드로 넣고
  ICP 잔차로 고르는 비용이 싸다. → B4
- **탐색 범위 제한이 없다.** 키프레임 간 실제 변위는 1~2 m 인데 상관 피크는
  전 영역에서 찾는다. 물리적으로 불가능한 피크를 배제하면 잡음 피크가 준다. → B7

## 실험 목록

판정은 전부 **병진오차 중앙값**과 **0.25 m 게이트 통과율**. 대조군은
`a0-control`(= 승자 설정, 0.364 m / 33.0%).

### Tier A — 파라미터 스윕 (코드 변경 없음, 진행 중)

1차에서 "동률"로 떨어진 축들을 판별력 있는 측정으로 다시 본다. 1차의 기각이
측정 실패였는지 여기서 갈린다.

`erosion 0/4` · `sigma 1/4` · `ROI` · `radial-mean` · `DFT refine off` ·
`range_min 5.0` · `upsample 200`

### Tier B — 알고리즘 변형 (코드 필요)

| # | 변형 | 가설 |
|:--|:--|:--|
| B1 | CLAHE 제거 / clipLimit·tile 스윕 | 공백 지배 영상에서 대비평활화가 잡음을 상관에 주입 |
| B2 | 마스킹 정규화 상호상관 (Padfield) | 0 영역이 zero-shift 편향을 만든다 |
| B3 | 스펙트럼 대역통과 | 저주파(띠 포락선)·고주파(스페클) 억제 |
| B4 | 상위 N 피크 다중 시드 | 참 피크가 2등으로 밀리는 경우를 ICP 잔차로 건짐 |
| B5 | 극좌표 직접 상관 | 직교 변환의 보간이 얇은 띠를 뭉갠다 |
| B6 | Hann/Tukey 창 | 0 패딩 경계 누설 |
| B7 | 피크 탐색 반경 제한 | 물리적으로 불가능한 변위 배제 |
| B8 | 모션블러 배제 되살리기 | 죽은 조건을 켜면 흐린 프레임이 빠져 정합이 나아진다 |

### Tier C — bag 재생 확인 (10분/런)

Tier A·B 에서 **게이트 통과율을 유의하게 올린 것만** 올라온다. 여기서만 궤적
오차를 보고, 22% 복제 산포 규칙이 적용된다.

### Tier D — 그래프 층 (오프라인으로 답이 안 나옴, 진단 런)

사용자 권한 확장(2026-09-02): *"제약 조건을 만족해야 하는 건 분명하지만 실험할

## 판정 규칙

- Tier A·B: 오프라인 지표. 반복 실행이 결정적이므로(같은 입력·같은 코드)
  복제 산포는 0 이다. 차이는 그대로 차이다.
- Tier C: 궤적 오차, **22% 미만 차이는 결과가 아니다**. `cmp_at_common_pairs.py`
  로 공통 pairs 보정 후 비교.
- 최종 채택은 제약 4개(FFT·ICP 필수 / DR 최소 / 속임수 금지 / SSM·NSSM 필수)를
  모두 만족해야 한다.
