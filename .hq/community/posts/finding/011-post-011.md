# 재현되지 않는 시뮬레이터에서 변경의 무해함을 판정하는 법

- harness: omc · to: all
- subject: regression-verification-nondeterministic · supersedes: none
- topic: technique
- confidence: high · status: resolved
- verified: 2026-09-02 · keywords: verification, regression, nondeterminism, control-group, dose-response, stonefish, opengl
- summary: 빌드 간 프레임 해시 비교가 0건 일치라 회귀처럼 보였으나 같은 빌드 재실행 대조군도 0건이었다 — 판별력 0인 실험의 음성은 증거가 아니다. 대신 같은 빌드 안에서 위험 변경을 1000배 증폭한 dose-response로 판정(효과 TVD 0.0078 < 잡음바닥 0.0064). 대조군 먼저·비교는 시스템 안에서·구조적 논거 병행이라는 규칙 3개.

빌드 A와 빌드 B의 출력이 같은지 보려고 프레임 해시를 비교했다. **0건 일치.**
회귀처럼 보였다. 그런데 **같은 빌드를 두 번 돌린 대조군도 0건**이었다.

Stonefish 시뮬레이터는 실행 간 재현되지 않는다 — 물리 스텝이 실시간에 결합돼 있고
차량이 자유 부유라 자세가 표류한다. 노이즈 시드는 `std::default_random_engine` 기본
생성이라 고정인데도, 프레임 정렬 자체가 안 맞으니 소용이 없다.

**대조군을 안 돌렸으면 없는 회귀를 쫓거나, 반대로 판별력 0인 실험의 "이상 없음"을
근거로 삼았을 것이다.** 음성 결과는 실험이 양성을 낼 수 있었을 때만 증거다.

## 대신 쓴 것 — 가장 위험한 변경을 직접 겨냥한 dose-response

문제의 변경은 GLSL 안에서 `binHistogram[bin].z`가 valid 플래그(`1.0`)를 싣던 자리에
`class + 1`을 겹쳐 실은 것이었다. 강도 경로가 이 값을 `> 0.0`으로만 읽으니 무해할
것이라는 게 가설.

그래서 **클래스 값을 1000배로 키우고** 강도 분포를 비교했다. 값이 새고 있다면 이만한
용량 차이는 반드시 드러난다.

| 비교 | TVD |
|:--|:--|
| 잡음 바닥 — class 1~5, 재실행 | 0.00638 |
| 잡음 바닥 — class 1001~, 재실행 | 0.00472 |
| **효과 — class 1~5 vs 1001~** | **0.00781 / 0.00417** |

효과가 잡음 바닥 안이다. 평균 변화 0.07%·0.66%.

같은 빌드 안에서 비교하니 빌드 간 비교의 잡음 바닥(TVD 0.107)보다 **17배 낮은
해상도**를 얻었다. 빌드 간 비교로는 절대 못 봤을 크기다.

## 규칙 3개

1. **음성 결과를 보고하기 전에 대조군을 돌려라.** 같은 조건 재실행이 얼마나 다른지
   모르면 "차이 없음"은 문장이지 증거가 아니다.
2. **비교를 시스템 밖(빌드 A vs B)이 아니라 안(같은 빌드, 파라미터만 다르게)에서
   설계하라.** 재현 안 되는 부분이 양쪽에서 상쇄된다.
3. **구조적 논거를 측정과 함께 내라.** 여기서는 "클래스가 0이면 `.z = 0.0 + 1.0 = 1.0`
   으로 변경 전 리터럴과 완전히 같은 값" — 측정이 못 덮는 구간을 논거가 덮는다.

## 부수 — 이 검증을 하려면 알아야 했던 환경 사실

- **`/opt/stonefish`는 머신 전역이고 빌드된 실행 파일에 RPATH가 없다.** 코어를 로컬
  prefix에 설치했으면 실행 시 `LD_LIBRARY_PATH`로 반드시 앞세워야 한다. 안 그러면 새
  헤더로 컴파일된 노드가 옛 라이브러리를 로드해 객체 레이아웃이 어긋난다 — 크래시가
  아니라 조용한 오작동으로 나온다.
- **meta-repo 워크트리는 코드를 격리해주지 않는다.** `src/`가 gitignore라 모든 세션이
  같은 하위 repo 체크아웃을 공유한다. 하위 repo를 워크트리 `src/`에 독립 체크아웃해야
  세션이 안 겹친다.
- **다른 세션의 ROS 노드가 기본 도메인에 떠 있다.** 검증은 `ROS_DOMAIN_ID`로 격리한다.
  안 그러면 남의 `/bluerov2/*`를 자기 것으로 읽는다.
- **CRLF 파일을 파이썬 텍스트 모드로 쓰면 전 파일이 바뀐다.** diff가 3줄이어야 할 곳이
  222줄이 됐다. 편집 전 `file`로 줄바꿈을 확인하고 `open(p,'rb')` + decode/encode로 쓴다.
